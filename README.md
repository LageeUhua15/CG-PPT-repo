# 计算机图形学基础 · Pre 汇报资料库

这个仓库用来存放《计算机图形学基础》课前 Pre 汇报的 PPT 和配套资料。每次课前由 1–3 位同学汇报上一堂课布置的 Pre 任务，内容涉及算法解析、前沿调研、思考题等。资料按老师课件的章节整理，文件名和索引中都标注作者，方便后续几届同学查阅、参考选题。

仓库由课程助教维护，资料版权归各位汇报同学所有。

## 仓库结构

```text
CG-PPT-repo/
├── README.md                        # 仓库总说明
├── 光栅图形学/                       # 章节目录，名称与老师课件章节一致
│   ├── Index.md                     # 章节索引
│   └── pptx/                        # 该章节的 Pre 文件
│       ├── 4-8连通性对偶命题-周禹驰.pptx
│       └── 4-8连通性对偶命题-赵禹衡.pptx
└── ...                              # 后续章节
```

约定：

- 老师课件的每个章节对应根目录下的一个文件夹，文件夹名直接用章节名
- 每个章节文件夹内固定包含 `pptx/` 和 `Index.md`
- `pptx/` 存放该章节的汇报文件，一次汇报对应一个文件
- `Index.md` 是该章节的索引，记录主题、类型、作者、日期和文件链接
- 配套材料（代码、图片、PDF 等）较多时，在章节下新建 `assets/<主题-作者>/` 存放，并在索引备注中注明

## 文件命名

格式：

```text
主题-作者姓名.pptx
```

示例：`4-8连通性对偶命题-周禹驰.pptx`

- 作者姓名写在最后；多人合作时用下划线分隔，如 `主题-张三_李四.pptx`
- 同一份资料有新版本时直接覆盖原文件；旧版本可在 Git 提交记录中找回
- 文件名中不加空格

## 章节索引格式

每个章节的 `Index.md` 按下表维护：

```markdown
# 光栅图形学 · Pre 资料索引

按汇报时间先后排列，新条目追加在表格末尾。

| 序号 | 汇报日期 | 主题 | 类型 | 作者 | 资料 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 2026-10-15 | 4-8连通性对偶命题 | 思考题 | 周禹驰 | [pptx](./pptx/4-8连通性对偶命题-周禹驰.pptx) | |
| 2 | 2026-10-15 | 4-8连通性对偶命题 | 思考题 | 赵禹衡 | [pptx](./pptx/4-8连通性对偶命题-赵禹衡.pptx) | |
```

- 类型从「算法解析 / 前沿调研 / 思考题 / 其他」中选择
- 日期为汇报当天，格式 `YYYY-MM-DD`
- 备注可写合作者、配套材料链接、补充说明

## 查阅资料

- 按章节找：进入对应章节目录，先看 `Index.md`
- 下载单个文件：打开文件页面，点右上角 Download
- 仓库里的 PPT 是二进制文件，整体 clone 较慢；只需要部分资料时建议直接下载单个文件，确需 clone 可用 `git clone --depth 1 <仓库地址>`

## 资料提交

Pre 资料由学生助教统一收集和入库，汇报同学不需要自己操作 Git。

汇报同学需要做的：

1. 把 PPT 及配套材料发给助教
2. 告知姓名、汇报日期、主题和类型（算法解析 / 前沿调研 / 思考题 / 其他）
3. 如果 PPT 中有不适合公开的内容（个人信息、未发表数据等），提前说明

## 维护说明

收录一次新的汇报：

1. 把文件重命名为 `主题-作者.pptx`，放进对应章节的 `pptx/`
2. 在章节 `Index.md` 表格末尾追加一行，填写日期、类型和作者
3. 同一份资料更新时直接覆盖原文件，提交信息写明「更新 <主题> - <作者>」
4. 章节尚不存在时，在根目录按老师课件章节名新建文件夹，放入 `pptx/` 和 `Index.md`，并在 README 的章节导航表中补一行
5. 合并前检查文件名、作者和相对链接是否正确
